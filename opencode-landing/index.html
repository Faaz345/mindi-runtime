Three-Minute Setup

From zero to premium in 3 steps

1

Clone the proxy

Grab the lightweight router script — a single Python file with zero heavy dependencies. Works on Windows, macOS and Linux with Python 3.9+.

2

Run it locally

Start the proxy with python agentrouter-proxy.py. It spins up on localhost:8080 and shows a green Running status instantly.

3

Point opencode at it

Set the base URL in opencode to the local proxy, pick Kimi K3, GPT 5.6 Sol or Claude — and start a new session. That's it.
